# Твоє райфове передбачення ✨

Мобільний сайт у жовто-чорно-білому стилі з милим єнотиком 🦝.

- 200 унікальних передбачень українською: смішні, теплі, приємні, надихаючі, з характером і трохи шалені.
- Приблизно 20% результатів — справжні цитати українських авторів із назвою твору.
- Кнопка «Отримати передбачення» після першого натискання стає «Ще одне».
- Передбачення випадково перемішуються й видаються без повторів до завершення циклу з 200 текстів; прогрес зберігається в браузері.
- Адаптивний дизайн, керування клавіатурою, озвучування результатів екранними читачами та підтримка зменшеного руху.
- Без API, платних сервісів, зовнішніх шрифтів, бібліотек, аналітики та збирання даних.

## Запуск

Відкрийте `index.html` у браузері. Встановлення залежностей і збірка не потрібні.

## Безкоштовна публікація на GitHub Pages

У репозиторії відкрийте **Settings → Pages**, у **Build and deployment** оберіть **Deploy from a branch**, гілку **main**, папку **/ (root)** та натисніть **Save**.

Після публікації адреса буде:
https://16innochka95-svg.github.io/raifove-peredbachennia/

## Файли

- `index.html` — структура та український текст інтерфейсу.
- `styles.css` — оформлення й адаптація до мобільних екранів.
- `script.js` — передбачення, цитати та випадковий вибір.
- `raccoon.jpg` — надане головне зображення, 1280 × 853; на мобільному екрані показується без обрізання й спотворення пропорцій.

Редагуйте масиви `predictionGroups` і `quotes` у `script.js`, щоб змінити тексти. Для цитат зберігайте автора та першоджерело.

Це неофіційний творчий проєкт; передбачення створені для гарного настрою.


## Поточний склад архіву

200 передбачень і 4 цитати. Попереднє розширення цитат до 50 не було завершено; під час заміни зображення `script.js` залишено без змін.
